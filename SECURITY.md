# Security policy

## Supported versions

Fixes go into the latest release. Upgrade to it before you report.

## Reporting a vulnerability

Don't open a public issue. Report it through [GitHub's private vulnerability reporting](https://github.com/dev-marzahn/convex-workflow-migrations/security/advisories/new) with the version, the steps to reproduce it and what an attacker gains.

## Scope

This covers the `@dev-marzahn/convex-workflow-migrations` package, including its copy of `@convex-dev/workflow`'s client code. Report issues in `@convex-dev/workflow` itself to [Convex](https://github.com/convex/workflow/security), and issues in the Convex backend to [Convex](https://github.com/get-convex/convex-backend/security).
